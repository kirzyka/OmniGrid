# План плагинов OmniGrid

Документ описывает функциональность, планируемую к реализации в виде плагинов OmniGrid.

Плагины должны подключаться отдельно и расширять возможности Grid Core, не перегружая минимальное ядро функциональностью, которая нужна не всем пользователям.

## Базовые плагины

**Free / Open Source, лицензия MIT**

Базовые плагины входят в стандартную поставку или подключаются отдельно. Они полностью открыты и бесплатны.

### Sorting Plugin

Сортировка строк по клику на заголовок колонки:

- одиночная сортировка;
- множественная сортировка по нескольким колонкам;
- циклическое переключение состояний `asc` / `desc` / `none`.

### Filtering Plugin

Базовая фильтрация данных:

- текстовый поиск;
- числовые фильтры;
- фильтры по датам;
- выпадающие списки значений;
- операторы `equals`, `contains`, `greaterThan`.

### Column Resize & Reorder Plugin

Управление колонками:

- изменение ширины колонок мышкой;
- автоматическая подгонка ширины по двойному клику на границе колонки;
- изменение порядка колонок перетаскиванием в заголовке.

### Pagination Plugin

Разбиение данных на страницы:

- выбор размера страницы через `pageSize`;
- переключение страниц;
- отображение текущего диапазона и общего числа записей.

### Selection Plugin

Выделение строк и ячеек:

- выделение отдельных строк;
- выделение диапазонов с помощью `Shift+Click`;
- множественное выделение с помощью `Ctrl+Click`;
- выделение ячеек;
- checkbox selection;
- копирование выделенных данных в буфер обмена.

### Column Pinning Plugin

Закрепление колонок при горизонтальной прокрутке:

- закрепление слева через `pin: 'left'`;
- закрепление справа через `pin: 'right'`.

### Cell Editors Plugin

Базовое inline-редактирование ячеек:

- запуск редактирования двойным кликом или клавишей `Enter`;
- текстовые поля;
- числовые поля;
- чекбоксы;
- простые выпадающие списки.

### Column Visibility / ToolPanel Plugin

Управление видимостью колонок:

- скрытие и показ колонок;
- column picker;
- встроенная или выпадающая панель управления колонками.

## Платные плагины

**PRO / Commercial**

Платные плагины предназначены для сложных enterprise-сценариев: больших наборов данных, иерархий, расширенного выбора и экспорта.

### Row Grouping & Aggregation Plugin

Группировка строк и вычисление агрегатов:

- перетаскивание колонок в специальную зону группировки;
- иерархическое дерево групп;
- раскрытие и сворачивание групп;
- агрегаты `sum`, `avg`, `min`, `max`, `count`.

### Server-Side Row Model Plugin

Серверная модель данных для больших наборов:

- ленивая загрузка данных;
- infinite scroll / lazy load;
- серверная фильтрация;
- серверная сортировка;
- работа с датасетами на миллионы строк.

### Excel & CSV Export Plugin

Экспорт данных таблицы:

- экспорт видимых или всех данных;
- экспорт с учетом фильтров;
- сохранение стилей и группировки;
- форматы `.xlsx`, `.csv` и `.pdf`.

### Tree Data Plugin

Отображение вложенных структур:

- parent-child связи;
- раскрытие и сворачивание ветвей;
- поддержка организационных структур;
- файловые менеджеры;
- спецификации BOM.

### Master-Detail Plugin

Вложенные данные для строк:

- раскрытие строки;
- отображение дочерней таблицы;
- отображение произвольного кастомного компонента с деталями записи.

### Range Selection & Clipboard Copy Plugin

Расширенное Excel-like выделение:

- выделение прямоугольной области ячеек;
- копирование и вставка через `Ctrl+C` / `Ctrl+V`;
- автозаполнение через fill handle.

### Pivoting Plugin

Интерактивные сводные таблицы:

- построение кросс-таблиц;
- одновременная группировка по строкам и колонкам;
- изменение измерений и агрегатов пользователем.

### Advanced Filters / Filter Builder Plugin

Визуальный конструктор сложных фильтров:

- логические операторы `AND` и `OR`;
- группы условий;
- вложенные группы фильтров;
- сценарии фильтрации, аналогичные Jira и корпоративным CRM.

## Принципы реализации

- Логика плагинов должна оставаться framework-agnostic и размещаться в Core или отдельном пакете плагина.
- UI-части, например панели, редакторы и drag-and-drop, должны реализовываться адаптерами конкретного фреймворка.
- Базовые плагины должны быть доступны под лицензией MIT.
- PRO-плагины должны подключаться из отдельных пакетов и не попадать в базовую MIT-поставку.
- Каждый плагин должен иметь собственный публичный API, документацию и набор тестов.
